# DIMS Project

Frontend for the Direct Pharm Inventory Management System (DIMS). Built with Next.js, TypeScript, and Tailwind CSS.

Paired backend repo: [DIMS_BACKEND](https://github.com/Direct-Pharm-Inventory-Manaement/DIMS_BACKEND).

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app. The frontend expects the backend API to be running (see `DIMS_BACKEND`'s README) and reachable via `NEXT_PUBLIC_API_URL` (see `.env.local.example`).

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — build for production
- `npm start` — run the production build
- `npm run lint` — lint the codebase
